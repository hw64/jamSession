Welcome to jamSession. This is a WIP. It's possible this readme will be outdated.

Click to place notes.

Scroll on a note to adjust its length, maybe even by accident when you...

Scroll on the grid to pan around.

Pinch to zoom. Yes it's slow and off center. There were more important things.

Right click to delete notes.

Press space or the button to play/stop.

Press 1 and 2 to cycle between patterns. 

Press tilde to redraw the piano roll if you think it's broken for some reason.

Saving and loading will download/upload a file. But a "sesh" file is just a json file. For now.

Click on an instrument to choose it, and right click on it to customize it.

The code is bad and will change dramatically. Dear my adoring fans: Don't PR me all at once.
